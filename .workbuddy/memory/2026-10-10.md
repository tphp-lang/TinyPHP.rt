### 修复的真实 bug（编译器/运行时）
1. **TV_* 宏参数名与成员 token 冲突**：`TV_INT(i)` 的参数 i 替换掉 `.u.i`（M0 未编译未暴露）——参数改名 iv/dv/pv
2. **bin_new(P_ASSIGN) 产出 A_BINARY 标签**——赋值节点进二元分发 → unknown binary operator；parse_assign_level 改用 ae_new(A_ASSIGN)
3. **op_return use-after-free**：tm_free(f) 后读 f->prev
4. **CallRec dst 记录错位**：dst 在 DO_FCALL 指令上（INIT 时 tr=UNUSED），RETURN 永远不写返回值
5. **op_return 无 DEAD 检查的 tval_release**：GC sweep 自引用环 → tarr_free 递归重入崩溃；tval_release 加 `color==DEAD → rc-- return`

7. **数组插入顺序**：freelist 复用破坏 PHP 插入序——改为追加式（nNumUsed 语义）+ 空洞压缩 arr_compact
8. **tstr_is_numeric 尾空格**：PHP8 不允许（原来 trailing_ws_ok=true）
9. **空字符串字面量 ""**：build_string 返回未初始化 u.name（垃圾指针）
10. **插值子解析器越界**：parse_sub_expression 的 lex_init 按 strlen 定 end——part 是主缓冲片段，子 lexer 读穿；`p->lx.end = src + len`
11. **lex_number 指数被 !is_float 挡**：`1.0e15` → `1.0` + ident `e15`；PHP float 也可带指数
12. **lex `...` 无 token**：P_ELLIPSIS 漏了 → spread 崩
13. **bin_opcode 漏 P_GT/P_GE**：`>=` 触发 unknown binary operator
14. **match JMPNZ 目标反了**：patch 到 body 之后（跳过 body）→ 改为 jump-into-body + jskip JMP（多 cond 不匹配时越过）
15. **spread 整数键**：PHP spread 整数键 re-indexed（append），字符串键保留——原来 set(key) 覆盖同名键元素
16. **(-3)**2 的 pow 断链**：括号组提前 return 跳过 maybe_pow；括号组/cast 后都接 maybe_pow
17. **括号内嵌套三元误报**：u.tern.paren 标记，检查时豁免
18. **var_dump 嵌套数组双倍缩进**：dump_val 对 T_ARR 重复 pad
19. **strict_eq bool**：true===false 返回 true——bool 分支补同值判断
20. **unset($g) 函数内语义**：PHP 只断别名全局保留——编译期 no-op
21. **empty() 任意表达式**：非 VAR/DIM 直接 !bool(expr)
