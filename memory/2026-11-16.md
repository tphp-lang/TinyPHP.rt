## -static 三臂 A/B（同日，销案）

- **三臂实测（static-full / dyn / wp 定向 `-Wl,-Bstatic -lwinpthread -Wl,-Bdynamic`，同源各完整 build.cmd 一遍）：产物功能等价**——文件同尺寸 15427584B、节表（名/尺寸/vma）md5 三臂相同（MD5 差异仅 PE 头时间戳）。-static 与定向静态在本工具链（clang 22.1.7，/c/env/msys2 固定环境）对纯引擎构建是 **no-op**。
- 根因核实：引擎源码（src/ + ext/ 九包）**零 clock_gettime 引用**（grep 实证）→ 无 winpthread 符号引用 → 三种链接旗标无可拖入之物。41daece 的 winpthread 病灶真实来源 = **teb 扩展（civetweb）经 ext relink 链入 exe 时**的 time64 重定向（bug 文件取证链互证）——**-static 的真实防护面 = pkg.c ext_engine_libs（重链行）；build.cmd 行是保险带（当前 no-op 但保留）**。
- **销案结论**：①无布局代价可言 → CI windows serialize −14% = 纯噪声背书；②定向静态方案无必要（产物已等价）；③**-static 保留原样**（无害 + ext 重链面防护）；④**break-in-loop 立项基线干净**：本机 exe 无任何链接配置混杂，CI 面判读维持修正版（A7 编译成本 + 单轮噪声）。

## break-in-loop 立项（B1，规格稿已呈待拍板）

- **规格稿落 PLAN/osr.md §9**（发现② 升格正刀）：循环体含 break 函数两级全拒（eager emit trap=3 + OSR L5828）→ 该形态 100% 解释器；bench 14 项零 break（grep 实证）→ **clean11 影响 ≈0，覆盖面立项（M2 口径外）**。
- **机制**：循环帧 +loop_exit[]（loopcond 分支 E=T 处设）+ if-handler 4 处 fail 检查前插逃生门（TR_END@loop_exit → bp_push 暂存 END + 转 trap_ret，镜像 P0-14 批5 continue lb_push）+ loopcond 出口 MERGE_N（bp+false 区）→ pc=E。**stash 而非直通的根因**：trap 协议单值无 CFG，直通丢"其余分支继续体+体尾回边"结构；stash 保证回边必存在（LOOP 合法）。**三族同点**：foreach 出口判定 = FE_FETCH 后 JMPZ 由同一 loopcond 分支消费（jit.c:5550 形态零适配）→ while/for/foreach 一刀全覆盖。
- **保守边界（v1 维持拒，零回归）**：体顶裸 break/continue-site 的 TR_END@exit-stop（无回边 LOOP = 非法 IR，与 §8.7 发现④同源）、`if(c)continue;else break;` 双侧逃生（TR_RET 退化形态）、break N≥2、switch 内 break（target=switch 出口 ≠ E）。
- **风险门**：deps/ir O1 FOLDING/CSE × LOOP+出口 MERGE = 批2-3 tv_copy 同族域 → 三态矩阵验收；acc_phi 不跨出口读（出口读槽 belt，c7 锁定）；bench 零 break → clean11 必零移动（移动即 bug）。
- **工作量**：jit.c ~60 行 + test-osr-007 九场景三方对拍（PHP 8.5.1/JIT=0/JIT=1）+ 探针 probe_break_cover.php——约 1 工作日。
