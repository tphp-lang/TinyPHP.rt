## 批3-3：INIT_SMCALL 静态方法直调（同日续作，230/230）

**勘察**：INIT_SMCALL 不在白名单 → 含 `C::m()` 的函数整体拒编；op 编码无 ic（a1=kind/a2=argc/ar=key lit，运行期才解析）——直调必须在 JIT 侧编译期解析并守卫全部运行期语义。

**实现（src/jit.c + vm.c opseq 一行）**：
- `jit_smcallee(caller, op, &rej)`：解析 op_init_smcall 的**静态可判子集**——kind 0 self::=caller->decl_cls、1 parent::=decl->parent、3 字面量 `Cls::m`（**只查不 autoload**，未加载→拒）；要求 m->fn && is_static && !abstract；可见性=同一 `tphp_vis_ok(m->visibility, m->decl?:cls, caller->decl_cls)`。**拒=回解释器走完整语义**：static::（LSB）/动态名/enum from/tryFrom/cases/native static/__callStatic/__construct/实例转发/spread。不松于运行期的论证：运行期 vis scope（called_cls 链）⊆ decl 子类链，vis_ok 链式规则下编译期判定恒不松。
- **op->ic 作 per-site 缓存**（op_init_smcall 全库不读 ic——批2 INIT_DYN 同款零读者直用；对齐指针原子写无撕裂）；eligibility 解析+缓存 → jit_compile_callees 同扫（阈值逻辑共用）→ emit 读 ic。
- emit 复用 A 直调机械：`p_sm` 标志 + **poff=1**（slot0 UNDEF 一条 store + 参数 1.. + [1+n_params..nslots) UNDEF；nslots≤9 仍复用 r_call_args）；INT 契约逐参 IF（非 INT → RETURN 0 deopt → 解释器重跑）。
- **vm.c opseq 派发表 +INIT_SMCALL**（真 handler 执行）——防 p_seq 回放序列内静默跳过（`new C(self::x())` 实参形态）；emit 侧 p_seq 内 pc++ 跳过交给回放。

**对拍收获（重要语义实证）**：**PHP `__callStatic` 对"不可访问"（private/protected 跨类，非仅未定义）静态方法同样接管**（`Sm::secret()` private + 有 __callStatic → "magic:secret" 而非 raise；无 __callStatic 类才 raise）——双端逐字一致，tphp 语义天然正确，测试首版 EXPECT 写错已修。

**验证**：tests/oop/test-smcall-jit-001.php（13 例：直调 loop/self::+protected 同类/parent::/继承静态/非 INT deopt/JIT'd 实例方法发起方/跨类 private raise/protected 跨类 raise/__callStatic 不可访问接管/__callStatic 未定义/static:: LSB/enum from）双端逐字节一致；TPHP_JIT_DEBUG 实证直调站点全 `eligible=1 + compile + ir_check=1`、拒因逐条符合设计（SMCALL visibility / not user-static / callee ineligible）；**230/230**；bench 13 项零回退（call 8.2、fib 13.4、array-read 9.9、kv 52.0、object 52.1）。

**验收**：改动面 src/jit.c（+~100）+ src/vm.c（opseq +1 行）+ 新测试；230/230；ir_check 全 1；文档同步；停在提交线。

## P0-16 批1：intern 表 O(n²) 修复（用户拍板 P0-16 后即日落地）

**根因（勘察实证）**：`tstr_intern`（string.c:53）= **固定 4096 桶链表**（`idx = h & 4095`，`static _Thread_local InternSlot *intern_tab[4096]`）——唯一键累积时每桶链长随 n/4096 线性增长，每键 intern（tarr_set 字符串键路径必经，array.c:170-173）都扫链 → 总比较量 ≈ n²/8192 → kv-fill 超线性。gc_collect 无自动触发点（grep 证）→ GC 扫描假设排除。

**修复（src/string.c 单文件）**：intern 表改可扩容链表——`intern_tab` 指针化 + `intern_bcap/intern_n` 计数，负载（条目/桶）达 2 时 `intern_grow()` 倍增 rehash（按 `p->s->hash` 重挂，均摊 O(1)）；thread_local 语义不变（各线程独立表）；驻留策略不变（批2 再评估）。

**实测（同探针三规模）**：
- 修前：1038→1502→3384 ns/ins（超线性），500k=1692ms
- 修后：**640-950 ns/ins 恒定（各规模平坦）**，500k=**470ms（-72%）**
- PHP 恒 ~94ns（剩余 ~8× 恒定差距=批2 常数地板：键串 alloc 4×/tarr_set 双 arr_find/TStr 96B tail/intern slot malloc）

**验证**：230/230；bench 13 项带内（logstat 100.2-100.7 三连，唯一键 4000 未触发扩容；kv-read 51.6-56.6、serialize 371-378 噪声带）。
