### 结论概览
- 主体健康：类模型/继承/接口/trait/enum/提升构造/12 个魔术方法（除 __destruct）/静态晚期绑定(方法)/对象比较/动态分发/同帧异常——与 PHP 逐字节一致；PLAN/01 §11 OOP 验收示例双跑 4 行全同
- **P0-1 跨帧异常传播断裂**：调用只要是 try 体最后一条 op，调用方 catch 完全接不住（函数/方法/闭包/深层/builtin raise 全中；try 体调用后还有语句就能接住）。根因：compile.c S_TRY 的 `end_pc` 排他（指向边界 JMP，vm_unwind 要求 `pc < end_pc`），而 DO_FCALL 压帧前把调用方 pc 前推过边界（vm.c:1162 `vm->x.frame->pc++`）→ 差一错误。修法：compile.c 三处 ex 条目 `end_pc = end` → `end + 1`（边界 JMP 纳入区内）
- **P0-2 __destruct 永不触发**：rc 归零/unset/脚本结束/嵌套对象全不调
- **P1-3 typed 属性全线 Parse error**（`public int $x` 带不带默认值/static int/trait 内）——doc/stdlib.md 与 PLAN/01 §2 声称"属性类型声明 ✅"，自相矛盾；提升参数带类型却正常；连带独立 readonly 属性无法表达（PHP 要求 readonly 必须有类型）
- **P1-4 用户异常类体系断裂**：`extends Exception`→Class not found；`catch(MyErr $e)`→Unknown exception class；`class_exists('Exception')`=false（TExClass C 表与 TClass 两套系统）；普通对象 throw+catch(Throwable) 反而能用
- **P1-5 Closure 类缺失**：Closure::bind/fromCallable → Class not found（PLAN/01 §5 声称 ✅）
- **P2-6 nullsafe `?->` 缺失**（parse.c:666 "lands in M3" 占位桩）——PLAN/01 §11 验收示例第一例就在用它，文档与实现矛盾
- **P2-7** `new X(命名参)`/`new X(...$arr)` 缺失（compile.c:1325 占位桩）
- **P2-8** 方法调用命名/展开参数缺失（compile.c:1393/1433 占位桩）
- **P2-9** `$obj->m(...)`/`Class::m(...)` first-class callable 缺失（compile.c:1354 占位桩；函数/闭包形式 ✅）
- **P2-10** 类常量表达式全拒（`self::B+1`/`'x'.'y'`/`1+2*3`/数组常量）；typed 常量(8.3)❌；final const ✅；enum 常量❌（Undefined constant）

### P0-2 __destruct（已完成，连带修了 4 个既有 bug）
1. **op_new_user 引用计数账不平**（最深根因）：rc++（ctor-invocation）在无构造器/原生构造器/ctor RETURN 三条路径都没抵消 → 每个对象恒定多持一个引用，rc 永远归不了零 → 对象全部泄漏、__destruct 永不触发。修：无构造器 dst 分支补 rc--；原生构造器两分支补 rc--；ctor RETURN 去掉 addref（移动语义）
2. **vm_unwind 构造失败对象不释放**：补 ctor 帧弹出时释放半成品（DTORED 标记，不跑析构——PHP 语义）
3. **vm_call_magic 陈旧异常误判**：unwind 途中触发的析构会带着旧异常进来，收尾检查误判为"魔术方法抛出"→ longjmp 打乱展开。修：记录 pre_ex，只传播新异常
4. **main_frame 悬空**：主帧 RETURN 后 global_slot UAF。修：销毁时置 NULL + 判空
- 实现：mem.c tobj_free 前置析构逻辑（引擎引用保命/复活判断 rc>1/GC defer 两段式）；vm.c tphp_obj_run_dtor（局部 setjmp 换 vm->x.unwind 防析构异常外窜）+ tphp_run_shutdown_dtors（快照+DTORED+引擎引用）；两个 VM 入口接入
- **GC 连带修**：gref 模拟完全不统计 OBJ 属性边（含对象的环永远误判可达）；sweep 终局只释放 STR/ARR（OBJ/CLO/EX 全泄漏）→ 补 OBJ 分支 + gref_dec 助手 + 全 kind 释放
- **sort/rsort/array_unshift 空操作**（既有 bug）：写回 args[0]（实参副本）调用方收不到 → 全部改原地排序/前插（照 usort 模式）
- 新增测试：test-destruct.php / test-destruct-gc.php / test-array-inplace.php
- 压力验证：20 万对象创建/析构/数组拆卸与 PHP 逐字节一致
- 既有缺陷记录：`global $x` 若顶层从未出现则主帧无槽（"global slot missing"）；`$obj::$x` 实例静态访问不支持
