## 刀16：FETCH 值直达（TPHP_FETCH_FWD，默认开）——read −20.7% ✅

**选靶**：11-06 收工勘察并列候选"FETCH→ADD 值直达（MERGE 墙旧案，spec 下路径更短可重估）"。11-09 勘察实锤：DEBUG=2 IR 剖面（tools/probe_fetch_wall.php 新建）显示 spec=1 循环体剩 = bound 单菱形 + take 2 store + MERGE + ADD dst load——墙 = **dst TMP 槽往返（2 store + 1 load/迭代）**。

**切面（A 模式：phi 桥接，不动控制流——10-31 否决的"纯值流"在批1-3+刀15 后重估成立）**，src/jit.c 单文件：
- **emit gate**：`fetch_fwd_enabled() && !fold_add && 配对 ADD（镜像 spec_scan RMW：dst CV + 另一 src==FETCH dst）&& !stop_has(pc+1) && !is_jump_target(pc+1) && thin 三条件（spec_c+spec_body_tmp+ar 恒等）`——stop/jump-target 排除防 fwd 跨块失准；
- **hit 线**：`LOAD element pay` 免 take 16B store；**miss 线**：`load dst` 作 phi 输入（spec 下越界恒 raise → 实死线，值亦真——零新语义依赖，dimic_miss 原样）；**MERGE 处 `PHI I64`** 桥出 → JitC 新字段 `spec_fwd_pay/valid/kind/idx`；
- **消费（lower_binop）**：kind+idx 双等（防 CONST lit 撞数）→ pa/pb 直取 phi；消费即清，与 spec_tmp_valid 同生命周期**五处同步**（FETCH 尾置/清、spec 出体清、guard 激活清、guard 失败清）；
- **deopt 物化**：spec 双 INT 快线溢出 RETURN 前补写 tmp 槽（冷路 2 store）——OSR 从 ADD pc 重跑读槽；槽恒 UNDEF（preheader 消灭+直达不写）裸存安全；慢线 deopt 不可达（fwd ⊂ spec 快线双证）。

**IR 实证**（ir_check=1 双级）：热路 take 2 store + ADD dst load → phi+miss 冷 load，**每迭代净省 3 内存操作**；size 655→663（+8B=物化冷路，热路净减）。

## 刀19（首调成本黑箱归因 → 静态直调非 INT 慢路）：prebody 黑箱=deopt 双跑，根因 INT 契约；附 HEAD 正确性 bug（AAB5）一并修复

**归因链（统一时钟插桩 TPHP_CLOCK，uv_hrtime 同纪元切分，一次性探针已随刀收口移除）**：
1. 刀18 的"prebody 13.6ms 不可归因黑箱"是**记账错觉**：闭包首次执行在 `logstat($log)` 处 **DEOPT（jok=0）→ 解释器从 pc0 整函数重跑**，而段计时（SEG）只记**第二次运行**的值 → attempt1 的半截身体（≈一次 make 全跑）被算进 prebody。冷态时钟轨迹：prebody=8.46ms **全归因**（dispatch 0.35 + 编译链 8.10 + 帧 0.08 + 入口 0.04），无黑箱。
