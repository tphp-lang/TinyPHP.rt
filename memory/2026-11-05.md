## 刀3：槽级标量写者分析（回收刀2 门税，11-05，已落地未提交）✅

**实现（src/jit.c，约 +150/−25）**：
- **`jit_scan_slot_writers(fn, hot)`**：流不敏感全函数 fixpoint（hot 乐观 0 起步、写者约束单调降级、≤nslots+1 轮收敛）。写者分类：
  - 无条件标量：tval_{add..shr,neg,pos,bit_not} 只回 int/float 或 raise（value.c 实证 tval_add 走 to_num 数值双态、BW_* 走 tval_to_int 回 int——**binop 永不产引用计数**）、cmp/bool 恒 bool、CAST ct∈{1,2,3}、ISSET_* 恒 bool、UNSET_CV 写 UNDEF；
  - PROP 类传播：COPY/ASSIGN/INC/DEC 结果类=源类（**INC 原位写 a1 是恒等传播无需标**；INC 可回写字符串→不可无条件白名单 ✓）；
  - 无条件 hot：RECV/FETCH 元素/CONCAT/ARRAY_INIT·APPEND·ASSIGN_DIM(a1 autoviv)/CLOSURE_INIT/NEW_USER/FETCH_PROP/FE_RESET/DO_FCALL(返回任意，ret_type 收紧留后续批)/CONST 非标量字面量；
  - 入口态预填：捕获 [0..n_cap)、方法 slot0；参数由 RECV 覆盖（JIT→JIT 直写同槽同域）；解释器帧全 UNDEF 起；tphp 无引用类型零别名逃逸；
  - **隐写点**：FE_FETCH val/key 在 slots[a2+1]/[a2+2] 不入操作数 → 显式降级；a2 游标（裸 payload 恒 int）与 ar=bool 不标；
  - **读侧绝不降级**：JMPZ/JMPNZ cond、SEND 源、RETURN 值、INIT_* 状态（否则 cond TMP 被污染，cmp 门白丢）；
  - **is_main 全槽保守保门**（关键勘误）：`global_slot` 直接返回 `main_frame->slots[i]`（vm.c:329）——带 `global` 的函数（FETCH/ASSIGN_GLOBAL 白名单外=纯解释器）随时写主帧槽，操作数流分析对 main 不封闭。tests/bench 顶层脚本形态因此零回收（预期内）；CI perf 走 bench-vs-php **闭包形态**不受影响；
  - 未知 opcode（OSR 白名单外/ASSIGN_PROP·UNSET_PROP replay 族）→ CV/TMP 操作数保守全降级（多保门=HEAD）。
- **查询侧 `dst_gate_needed(j,op)`**：kind 必查（CONST lit 下标撞槽）、未分析（`TPHP_SLOTGATE=0`/calloc 失败）→ 保门；**15 个 rel_dst_gate 位点全部接入**（lower_binop/cmp×2/BOOL_NOT/BOOL_VAL/CAST×3/incdec×2/call 结果×3/OP_CONST/fold）。错判方向 = 只可能漏释放=泄漏（探针拦），不会双释放。
- 分析钩子在 tphp_jit_compile 与 tphp_jit_compile_osr 双入口（calloc/free 配对）。
